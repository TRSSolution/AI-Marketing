# Workflow 03 - Content Review

## Objective

Review and improve the generated content before publishing.

## Input

- Draft content from Workflow 02
- TeamSeafarers AI Marketing Brain

## Process

1. Check grammar and spelling.
2. Verify factual accuracy.
3. Ensure the content solves one customer problem.
4. Verify the 80% Value / 20% TeamSeafarers rule.
5. Improve clarity and readability if required.
6. Approve or reject the content.

## Output

One approved content draft ready for image generation.
