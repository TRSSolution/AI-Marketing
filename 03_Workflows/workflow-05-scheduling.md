# Workflow 05 - Scheduling

## Objective

Schedule the approved content and image for publishing.

## Input

- Approved content from Workflow 03
- Approved image from Workflow 04

## Process

1. Select the target platform.
2. Assign the publishing date and time.
3. Attach the approved image.
4. Verify formatting and links.
5. Send the content to the Publisher.

## Output

One scheduled post ready for publishing.
