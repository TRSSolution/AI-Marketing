# Workflow 04 - Image Generation

## Objective

Create a professional image that supports the approved content.

## Input

- Approved content from Workflow 03
- TeamSeafarers Brand Kit

## Process

1. Understand the main message of the content.
2. Create one supporting image.
3. Follow the TeamSeafarers brand colors.
4. Keep the design clean and professional.
5. Ensure the image supports the content.

## Output

One branded image ready for publishing.
